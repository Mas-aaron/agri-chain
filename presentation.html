Innovation (40%) — AI Architecture

MindSpore-Powered On-Device Disease Detection

🏗️ Architecture: MobileNetV2

Transfer-learning on MindSpore with nn.SoftmaxCrossEntropyWithLogits. Trained on Huawei ModelArts with Ascend acceleration.

📱 Custom Flutter Plugin

Built a native MindSpore Lite Flutter plugin (Java + C++ JNI → Dart). First-of-its-kind integration enabling .ms model inference inside Flutter via platform channels.

🔄 End-to-End Pipeline

Train (.mindir) → converter_lite → Optimized .ms → On-device inference. Fully offline capable — critical for rural areas.

# MindSpore Training Pipeline from mindvision.classification.models import mobilenet_v2 network = mobilenet_v2(num_classes=4) loss = nn.SoftmaxCrossEntropyWithLogits( sparse=True, reduction='mean' ) opt = nn.Adam(lr=0.0005) # Export for mobile export(net, input_tensor, file_name="maize_disease", file_format="MINDIR") # Convert to MindSpore Lite converter_lite --fmk=MINDIR --modelFile=maize_disease.mindir --outputFile=maize_disease_fp32 --inputShape="1,3,224,224"

Data pipeline: Resize → RandomCrop → Flip → ColorJitter → Normalize → HWC2CHW

Innovation (40%) — Blockchain & Tokenization

AI Predictions → Bankable Digital Assets

Our core innovation: ML yield predictions are tokenized into ERC-1155 "Future Harvest Contracts" on Huawei BCS. This is the first system where an AI model output directly underpins a financial instrument for smallholder farmers.

🪙 Yield Tokens

Each kg of predicted yield = 1 token. Farmers own tradeable digital assets.

🏦 Collateralized Loans

Tokens locked as collateral. Banks lend at 12-18% vs. 25-40% informal rates.

🛒 Token Marketplace

Buyers purchase futures directly. PesaPal mobile money integration.

📜 Immutable Ledger

Full farm-to-fork traceability. QR-code verification for consumers.

// Hyperledger Fabric Chaincode (Go) type YieldAsset struct { AssetID string TokenID string FarmerDID string // DID identity PredictedYield float64 PredictionConfidence float64 MLModelVersion string MLModelHash string // integrity RoverDataHash string // ground truth TokenAmount int64 TokenStandard string // "ERC-1155" Collateralized bool CurrentValue float64 } type LoanAgreement struct { LoanID string AssetIDs []string // collateral LoanAmount float64 InterestRate float64 CollateralRatio float64 }

Reproducibility & Open Source

Fully Reproducible in 4 Steps

1
Train Models
Upload dataset to OBS → Open mindspore_disease_training2.ipynb on ModelArts → Run all cells → Download .ms files
2
Start Backend
cd backend/backend && pip install -r requirements.txt && uvicorn agrichain.main:app --port 8000
3
Deploy Chaincode
Upload Go chaincode to Huawei BCS console → Install on peers → Instantiate with InitLedger
4
Run Mobile App
cd agri-chain && flutter pub get && flutter run --release on ARM64 Android device
